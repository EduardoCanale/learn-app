# Places

Real places you know cold, each written out as an ordered walk. These are the
Routes a memory palace is built on.

Rules that make them work:

- **Only places you could walk blindfolded.** A place you half-remember gives
  you nothing; the whole technique borrows strength from spatial memory you
  already have.
- **Fixed, distinct positions.** Each Locus should be a thing that cannot move
  and cannot be confused with the next one. "The kitchen" is not a Locus; "the
  sink" is.
- **One Route per palace, permanently.** Reuse is what ruins loci — old images
  bleed into new ones at the same position. The app marks each Route `CLAIMED`
  or `free`; those marks are maintained for you.
- **Eight to fifteen positions** is the useful range for one Route.
