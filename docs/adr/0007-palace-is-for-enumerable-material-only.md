# A Palace is built only for enumerable material, never as a general retention layer

The tempting design is to make the memory palace a second retention system running alongside spaced repetition — every concept gets a locus. The evidence does not support it. Method of loci is well established for ordered, enumerable material and is thin for conceptual understanding; the strongest study on technical content (insulin and diabetes pathways) found 9.31 vs 8.10 on a ten-question MCQ, p<0.003, with the authors themselves cautioning it says nothing about permanence or meaningful learning, and that loci normally needs extensive training. Dunlosky's review rates the adjacent keyword-mnemonic and imagery-for-text techniques as *low* utility.

So a Palace is a specialised instrument. Claude builds one only when a lesson contains a genuinely enumerable set — a sequence of phases, a taxonomy, a fixed rule set. Everything conceptual stays with ordinary free-recall Probes, which is where the retrieval-practice evidence is strong.

A Walk is scheduled by the same FSRS queue as every Probe rather than by a parallel system. A Palace is, mechanically, a Probe whose expected answer is an ordered list — so it needs no second scheduler, and spatial ordering never has to fight due-date ordering for control of the session.

Rejected: a rendered 3D palace. The mechanism of loci is that the learner holds the space; externalising it onto a screen plausibly substitutes for the encoding rather than supporting it, and it is the largest build in the project by a wide margin.
